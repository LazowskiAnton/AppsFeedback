# AppsFeedback

Bug reports and ideas for my free Windows apps from the Microsoft Store. The apps are closed source; this repository only collects feedback.

| App | What it does | Links |
|---|---|---|
| <img src="icons/LoupeSmith.png" width="32" height="32" align="absmiddle" alt=""> **LoupeSmith** | A glass loupe that follows the pointer and magnifies what is under it — sharp pixels, a pixel grid, the color under the pointer; clicks go through, so you keep working while you look. | [Documentation](https://lazowskianton.github.io/AppsHub/loupesmith/) · Microsoft Store (soon) |
| <img src="icons/RulerSmith.png" width="32" height="32" align="absmiddle" alt=""> **RulerSmith** | The size of the control under the pointer and the gaps to its neighbours, in any app — hold Ctrl+Shift and point; read from UI Automation, in app units and screen pixels. | [Documentation](https://lazowskianton.github.io/AppsHub/rulersmith/) · Microsoft Store (soon) |

All apps are free, have no ads, no subscriptions and no telemetry, and run on Windows 10 and 11. The [apps site](https://lazowskianton.github.io/AppsHub/) has them all in 14 languages.

Looking for the Visual Studio extensions? They have their own [Feedback](https://github.com/LazowskiAnton/Feedback) repository.

## How to give feedback

Open [**Issues → New issue**](https://github.com/LazowskiAnton/AppsFeedback/issues/new/choose) and pick a form:

- **Bug report** — something does not work or looks wrong.
- **Idea** — a feature you would like to have.

Before you write, please search the [existing issues](https://github.com/LazowskiAnton/AppsFeedback/issues?q=is%3Aissue): if your problem or idea is already there, add a 👍 to it instead of a new issue — the 👍 count helps to decide what comes first.

### Please keep private things private

Issues here are public. Before you attach screenshots, hide company, product, project and person names, paths and anything else private, or replace them with neutral ones (for example `Contoso`).

### Language

English is preferred, but you can write in any language the apps support.

## What happens next

Each issue gets labels: the app it is about, its type and its status.

| Label | Meaning |
|---|---|
| `planned` | Accepted, will be done in one of the next versions. |
| `done` | Done; the issue mentions the version. |
| `needs info` | More details are needed — please check the questions in the issue. |
| `won't do` | Out of scope for the app; the reason is in the issue. |

There is no promised response time, but every issue is read.
